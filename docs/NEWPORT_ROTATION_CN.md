# Newport SMC100CC / PR50CC 循环旋转步进

更新：2026-09-09；状态：未发布、协议 fake 与虚拟联调通过，未实机验证。

## 运行规则

- 连接与恢复参数均不移动。起点支持“启动时当前位置”和“指定初始位置”；前者读取当前编码器位置作为 P0，后者使用设定角度。两种方式都会检查 READY 状态及所有扫描点的软件限位。
- 指定 P0 时，先用“移动到 P0”定位，或把已经就位的当前位置填为起点。开始扫描不自动移到起点；若当前不在 P0 容差内会拒绝启动，稳定到位后才启动采集及触发计数。
- 第 k 个有效触发移动到 `P[k % N]`。`P[i] = P0 + i × step_deg`；N 是包含 P0 的位置数，支持负步长。
- 例如初始 10°、步长 0.2°、3 个位置：启动 10°，随后每个触发依次 10.2°、10.4°、10°、10.2°……。
- 末点不会立即自动回跳；末点的下一个触发回到 P0。回跳为绝对定位，不归零、不按 360° 自动取模、不选择最短路径。
- 移动后要求控制器 READY 且位置落入容差，并持续稳定达到设定时间，随后保持至下一个触发。稳定计时期间位置超差会重新计时。
- 运动/稳定期间收到边沿，或两次计数查询之间累计计数跳增超过 1，立即错误停止并尝试停止运动；保留收到数和完成数，不合并触发、不补跑积压。
- 计数查询和状态回读存在延迟。忙闲边界采用保守的软件观测判定，不承诺硬件边沿与机械到位时间精确排序。
- 停止不回起点。“启动时当前位置”模式重新启动会更新 P0；“指定初始位置”模式保留原设定，若已离开该位置，需先移回 P0 再启动。

本功能独立于 DG/Vaunix 的“首触发 P0、累计积压补发”控制器，不改变原有任务。

## 接入硬件

1. 在已有 Python 环境安装可选依赖：`python -m pip install -e ".[instrument]"`。新增串口依赖为 `pyserial>=3.5`；虚拟运行不需要串口驱动。
2. 用厂商工具正确配置 SMC100CC 所连接的 PR50CC，使控制器位置单位为度；确认速度、归零方式和软件限位。退出厂商工具后再连接本软件。

   连接时软件分别读取控制器版本 `VE` 和旋转台标识 `ID?`。兼容现场固件返回的 `SMC_CC - Controller-driver version 3.1.2`，以及旧版 `SMC - Controller-driver version ...`、SMC100、SMC100CC 名称。`ID?` 可返回裸型号 PR50CC，也可返回 `PR50CC_PN:B2210116_UD:01/10/2021`；软件从首段识别型号，并在身份栏保留完整附加信息。若 ID? 返回其他型号，错误信息会保留实际回包供核对端口与地址，软件不会自动改写型号或控制器配置。
3. 添加设备，类型选择 Newport SMC100CC，地址填 `COM3::1`（实际 COM 口 + 控制器地址 1–31）。搜索只枚举串口；不会自动打开端口、归零或复位。
4. 首版一个物理串口仅允许连接一个控制器地址；同 COM 的第二个设备会被拒绝，未实现多轴串联会话共享。
5. 点击连接和“读取位置与状态”。未归零时点击归零；该操作会移动设备。已 READY 时直接定位，不自动发送复位。扫描本身从不隐式归零。
6. 在首页连接现有 NI 设备，选用此前验证的计数器和 PFI。外部脉冲为 3.3 V、3 Hz，参考地接 NI 数字地；准确产品型号、电平门限及脉宽仍以 NI MAX / DAQmx 身份和相应规格核实，不按“USB-6364”字符串猜测管脚。

串口协议：57600 baud、8N1、XON/XOFF、CRLF。使用 VE、TS、TP、SL/SR、VA、PA、OR、ST、TE；查询响应有地址与命令校验，超时、残缺回包或错包关闭会话，运动指令不自动重发。TS 读取会消耗错误位，驱动对非零错误立即报告，不在 UI 后台轮询中吞掉错误。

## 操作步骤

1. 打开“NI 循环旋转步进”，在上方“初始位置 P0”选择起点方式。“指定初始位置”可输入绝对角度（如 -5.2°），未连接设备也能预览点表；“启动时当前位置”沿用原来的起点规则。
2. 连接转台后点击“移动到 P0”，等待定位完成；或点击“使用当前位置”，重新读取实际角度并填入指定起点。然后在“NI 触发”标签选择已连接的 NI、计数器、PFI 和边沿。
3. 在“旋转参数”标签设置步长（绝对值大于 0 且小于 1°）、位置数、到位容差、稳定时间和运动超时。右侧点表自动列出 P0 至末点的目标角度、相对 P0 偏移和状态。
4. 首版默认：0.2°、10 个位置、0.01° 容差、30 ms 稳定、10 s 运动超时。启动扫描不会修改控制器现有速度；速度仅通过“应用速度”下发。
5. 指定保存目录，点击“开始循环扫描”。指定起点时先检查实际位置在 P0 容差内并连续稳定达到设定时间；等待状态变为“保持 / 等待触发”，再启用外部触发源。
6. 检查首边沿实际移到 P1、到位保持、最后一条回跳到 P0。完成数只在到位和稳定确认后增加。
7. 点击停止，等待线程结束和资源释放，再进行手动运动或其他 NI 任务。

位置数 N 的完整循环需要 N 个触发：P1…P末、P0。界面持续显示收到/完成、目标/实测角度、阶段、回跳次数和本步耗时。修改任务参数或恢复历史参数不操作硬件；NI 引用使用稳定设备 ID，删除后不自动绑定另一张卡。

### 位置总览与扫描点表

- 顶部三张卡分别显示当前位置（实际回读）、扫描位置（当前目标）和当前点号。运动过程中目标与实际位置可能不同；点号表示本次目标，达到容差并稳定后才计为完成。
- 未读取位置时，当前位置卡显示“—”。指定初始位置后，目标卡和表格显示按设定 P0 生成的绝对角度；只有“启动时当前位置”模式的未知起点才会使表格绝对角度也显示“—”。空闲时显示最近一次回读，可点击更新；扫描期间使用扫描控制器的持续回读，不由界面额外查询串口。
- 点表为只读预览，修改初始位置、步长或位置数会自动更新。指定模式的点表严格按设定 P0 生成，容差内的实测偏差不会平移点表；当前模式在启动时读取真实 P0。运行中保持实际点表不变。
- 当前点高亮显示保持、移动、稳定或回跳状态，并自动滚动到可见区域。“本圈已到达”仅表示当前循环已完成的位置，回跳开始后清除上一圈标记；完成回跳次数只在 P0 到位稳定后增加。
- 停止后保留本次点表及执行状态，修改参数或点击“读取位置 / 更新预览”后转为下一次扫描预览。断线时当前位置显示未知，但保留任务错误和执行计数；重新连接后需读取位置或重新启动扫描才能显示新位置。
- 点表支持最多 10000 个位置，按可见行绘制；小窗口可滚动查看，左侧“停止旋转 / 扫描”始终可用。
- 起点模式和指定角度均自动保存，也包含在完整配置导出包中；导入或重新打开页面只恢复设置，不移动转台或启动扫描。没有这些字段的旧配置默认使用“启动时当前位置”。

## 3 Hz 与回跳

3 Hz 的触发间隔约 333 ms。每一步必须容纳运动、控制器到位确认、稳定等待及软件通信开销；稳定时间是运动就绪条件，不是采集时间。

PR50CC 标称最高速度 20°/s，最小增量运动 0.02°；最小增量、编码器分辨率、绝对准确度和 UI 到位容差不是同一个指标。软件允许更细的数值输入，但不保证能实现小于仪器最小增量的物理扫描。不要把 0.01° 的软件容差当作转台绝对准确度保证。

回跳幅度为 `abs(step) × (N-1)`。例如 0.2°、100 个位置回跳 19.8°，仅最高速度下的匀速时间下限就是 0.99 s，无法跟上连续 3 Hz。该配置可用于较慢触发；3 Hz 时必须减少范围、降低触发频率，或让上游在回跳后等待就绪。程序不会跳过回跳或静默丢弃后续边沿。

## 可选连续采集

“联动连续采集”页勾选启用，输入 `ai0,ai1` 等通道、采样率、每块样本数、量程与端接方式。旋转任务一次租用 Newport 和 NI，在内部启动独立 counter 与 AI 任务；其他独立 NI 窗口仍不能争抢设备。必须在实机确认同卡 counter / AI 路由组合可用。

AI 在计数器武装前启动，贯穿 P0、运动、稳定和保持阶段，不因触发暂停、不推进运动。模拟输入使用现有硬件时钟与逐块保存路径，曲线只保留有限显示窗口。AI 启动失败、计数器资源冲突、采集失败或写盘失败会停止整个旋转任务。

每次运行建立独立目录：

- `config.json`：设备记录、控制器身份、起点模式、指定 P0、启动时实测位置、稳定检查后的实际位置及绝对点表、步进参数、NI 触发/采集配置、当前速度。
- `rotation.csv`：主机 UTC 与 monotonic 观测时间、事件、阶段、触发数、完成数、点号、目标/实测位置、耗时与错误。
- `analog.csv`：可选的完整多通道原始样本，沿用连续采集 CSV 格式。
- `rotation.csv` 中的 `analog_block_received` 事件记录块首样本号、块长度和采样率，便于定位收到的数据块。

**阶段时间是主机观测时间，不是逐边沿硬件时间戳。一个 AI 数据块可能跨越多个运动阶段；块收到时的角度不能赋给整块样本。** 本版不输出伪精确的逐样本角度标签；需要严格同步时应进一步增加硬件标记/时钟路由。

## 无硬件验证与实机验收

首页“创建虚拟实验室”现在包括 Newport，共五台虚拟设备。打开虚拟 Newport，开始扫描后逐次点击“虚拟触发 +1”，每次等待保持状态；可在移动中再点击一次验证忙时停止。模拟器包含按速度计算的运动时间和回跳，但不模拟真实负载、加速度、回差和机械振动。

自动测试覆盖协议格式、错误位、限位、不重试、首点、双向循环、忙时/稳定期触发、跳增、长回跳、停止、超时、租约、同卡虚拟连续采集、界面按钮及持久化。实机仍须验证：正确配置和归零；单步及整轮回跳；3 Hz 持续运行；运动中停止；拔线错误；同卡连续采集与数据连续性。
