# 完整配置导入与导出

更新日期：2026-09-08。此功能用于软件更新、重装或迁移时保存设备与实验配置。

## 更新版本的推荐步骤

1. 在设备中心点击 **导出配置**，保存一个 `.json` 文件。导出会立即读取已打开设备窗口的当前参数，不需要等待自动保存，也不会操作硬件。
2. 更新软件。相同 Windows 账户、相同数据目录下，普通代码更新通常会继续使用已有配置；无需每次重新添加设备。
3. 需要恢复或迁移时，在新版本设备中心点击 **导入配置**，选择之前导出的文件。
4. 预览设备、参数和已保存任务数量。导入采用**整体恢复**，会替换当前配置；原配置自动备份。
5. 保持勾选“导入后重新连接备份中已连接的设备”，点击“备份并导入”。连接地址无需重新输入，软件会尝试重新建立这些设备的连接。
6. 打开设备设置窗口，即可看到恢复的参数。需要改变硬件输出或启动实验时，再点击相应的应用或启动按钮。

## 配置包包含什么

| 内容 | 范围 |
|---|---|
| 设备列表 | 稳定设备 ID、设备名称、型号类型、资源地址及连接方式 |
| 设备参数 | DG4000、Vaunix、NI、Newport、通用 SCPI 的已保存设置；导出时刷新已打开窗口的当前值 |
| 扫描参数 | 单设备窗口中的扫描轴、点表、Newport 步长/位置数/NI 引用及其他自定义参数 |
| 保存的任务 | `step_tasks.json` 和 `linkage_tasks.json`，包括当前跨设备任务 ID |
| 连接恢复记录 | 导出时处于已连接状态的设备 ID，用于导入后重新建立连接 |
| 校验信息 | 配置包版本、软件版本、导出时间、各配置文件的 SHA-256 内容校验值 |

设备 ID、任务引用和点表保留原样，不按显示名称自动重新绑定。对旧版本的位置式参数键保留原结构，由现有窗口的兼容迁移逻辑恢复。

不包含采集 CSV/TXT、运行日志、波形数据、厂商驱动/DLL、仪器内部非易失存储或正在运行的硬件任务。输出保存目录等路径作为参数原样保留，迁移电脑后应检查这些路径是否存在。跨设备任务窗口中尚未点击“保存任务”的编辑不属于已保存任务，请先保存后再导出。

## 导入与连接的行为

- 导入前停止扫描、触发和模拟采集，并等待连接、探测及其他后台操作完成；软件不会为了导入而悄悄中断正在进行的实验。
- 导入确认后关闭原来的设备设置窗口，断开旧会话，然后恢复文件，避免旧窗口的自动保存覆盖新配置。
- 勾选恢复连接时，只对配置包中记录的已连接设备建立新会话；不勾选则恢复配置后保持断开。
- 运行中的 USB/VISA/串口会话无法跨进程保存，恢复连接是按照原地址重新连接。硬件不存在、NI 设备名或 COM 编号改变时会明确报告连接失败，需要在设备中心修正地址。
- 设备参数恢复只更新界面，不自动应用信号输出、开启 RF、归零、移动旋转台或启动采集/扫描。
- 已删除设备的旧任务引用会保留，并在导入预览详情中提示。不会把它自动绑定到另一台设备。

## 备份与故障恢复

默认本机数据目录是 `%APPDATA%\RigolGeneratorControl`。通过 `--data-dir` 或 `RIGOL_GUI_DATA_DIR` 指定了其他目录时，以指定目录为准。

每次导入前，旧配置保存到当前数据目录的：

```text
config_backups/import_日期时间_唯一编号/
    configuration.json    可再次导入的旧配置包
    original.json         用于精确回滚的原文件字节备份
```

导入完成后，状态栏显示备份目录。想恢复导入前的配置，可再次“导入配置”，选择上述 `configuration.json`。

如果原配置已经损坏而不能构成有效配置包，仍会保留 `original.json`，并允许用有效配置包修复当前配置；这种情况下不会生成不可用的 `configuration.json`。

软件会先完整校验导入包，再写入本地文件。写入失败会尝试回滚；若导入过程中意外退出，下一次启动读取设备列表前会检测 `.config-import-pending.json` 并回滚原配置。回滚也失败时保留恢复日志和备份、报告错误，不继续使用混合配置。不要手工删除尚未完成导入的恢复日志，也不要让两个软件实例同时改写同一个数据目录。

配置包只接受四个固定配置文件，不解压任意路径，不导入可执行程序。损坏校验值、未知文件版本、未知设备类型、重复设备 ID/资源等会被拒绝，原配置不被覆盖。SHA-256 用于检查内容完整性，不是来源身份认证。支持的包版本与文件版本独立于软件版本号；未来不兼容格式需要明确升级支持，不静默降级或重置参数。

## 验证范围

测试覆盖五类设备、参数与任务往返、连接列表、旧参数键、缺失设备引用、自动备份、取消导入、运行时阻止导入、写入失败回滚和模拟进程中断后的启动恢复。UI 测试确认导出读取尚未自动保存的参数，并验证导入后自动连接虚拟设备且不启动运动。
