# 0.7.26：DG4000 幅度单位空回复的只读兼容

日期：2026-10-29。状态：源码与本地修复候选，不自动创建版本标签或 GitHub Release；当前正式下载仍为 [v0.7.25](https://github.com/Rechoncy/Rigol_Generator_GUI/releases/tag/v0.7.25)。原 0.7.25 本地候选和正式附件保留，0.7.26 使用独立交付文件与验证记录，不覆盖旧构建。

## 问题与依据

用户反馈 DG4162 通过 USB 使用回读时，`:SOUR1:VOLT:UNIT?` 返回空字符串，原程序因此丢弃整组快照。该命令是 DG4000 编程手册中 `[:SOURce[<n>]]:VOLTage:UNIT?` 的合法缩写；不能仅凭空串断定型号不支持，也不能从截图确定 USB 传输、仪器固件或回复接收中的具体根因。

手册还提供同通道 `VOLTage:HIGH?`、`VOLTage:LOW?` 查询，返回单位为 V，独立于仪器当前幅度显示单位。本版据此增加只读兼容路径，不通过切换仪器单位来绕过问题。

## 改动与边界

- 正常单位回复为 VPP、VRMS 或 DBM 时，保留原频率、幅度、单位和输出状态回读，不改变其显示含义。
- 仅在单位查询返回空值（空白或成对引号中的空内容也按空值解析）时，读取同一通道的高、低电平，并在前后各读取一组；两组一致且所有字段有效时，取 `HIGH - LOW` 显示 Vpp。界面明确显示“高低电平差；仪器当前幅度单位未知”，不将该差值冒充仪器面板原有幅度值或单位。不配对引号仍是无效非空回复，不触发兼容。
- 非空但未知的单位、查询超时或异常不进入兼容路径。高低电平前后不一致、任何数值或输出状态无效时，整组快照失效并显示未知，不保留部分结果冒充当前值。
- 整个操作只查询，不设置频率、幅度、单位、输出、负载或耦合，不自动重连、清缓冲或重放设置；不假定 50 Ω 或按 RMS 关系推算。CH2 单独回读只查询同一通道，不向 CH1 下发设置。
- 仍为手动快照，查询在共享会话内串行，结果与待应用编辑值分开；不是瞬时物理输出测量，也不证明扫频/调制在某个触发时刻的实际频率、幅度或稳定性。

## 使用与现场反馈

使用本版候选后，连接仪器，在“通道与波形”底部再次点击“回读频率 / 幅度”。正常回包仍显示实际 Vpp/Vrms/dBm；出现兼容来源说明时，Vpp 来自稳定的高低电平差，仪器当前幅度单位仍未知。无需为了回读先改仪器单位或应用编辑参数。

若仍失败，保留完整错误（包括命令和回复）、`*IDN?` 中的型号及固件、USB 连接方式后反馈；没有这些现场资料也不阻止依据已确认软件问题完成修复，但资料有助于定位空回复的传输或固件原因。失败时界面显示未知，不应拿旧快照继续判断当前输出。

本版尚未在用户 DG4162 USB 实机验收，不能声称已确认修复该设备。
