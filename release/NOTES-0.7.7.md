# Lab Control Center 0.7.7 发行说明

日期：2026-09-28；平台：Windows 10/11 x64。

## 外部触发与当前扫描值预览

用户反馈 v0.7.6 的“读取当前扫描点”在 SSG3021X 上不可用。本版改用普通 SSG3000X C01A 手册 3.4.5.29 / 3.4.5.30 的独立查询 `:SWEep:CURRent:FREQuency?` 和 `:SWEep:CURRent:LEVel?`，预览路径不再发送组合查询 `:SWEep:CURRent:DATA?`。

- 原生扫描页顶部显示“触发接收（仪器）”“触发积压（仪器）”“当前扫描值（仪器回读）”。外部触发线仍直接进入仪器，不增加 NI 计数或软件步进。
- C01A 手册未提供外部触发接收计数与积压查询，两项保持“未知”，诊断 JSON 为 `null`；不将查询次数、数值变化、点号或布防次数当作触发计数。
- 布防后点击“刷新当前值预览”，显示频率 Hz、幅度 dBm / mV / mVpp 和本机读取时间。电压按 50 Ω 正弦载波换算。两条查询顺序执行，可能跨扫描点，不代表同一次触发的同步测量。
- “自动刷新当前值（约 1.5 秒）”默认关闭，重开窗口不恢复。基础连接和常规刷新不查询实时扫描值；勾选后才随扫描状态轮询读取。忙时跳过，不积压软件刷新任务。
- 读取异常会关闭自动刷新并清除旧预览；重新布防、断开和停止也使旧预览失效。不以旧值、设定值或零填充未知数据。
- 保留 v0.7.6 的断线停止恢复：点击停止时重连同一资源、校验身份、单次关断并确认 OFF；停止扫描不关闭 RF。

## 验证与使用

新增 6 项回归，全量 **259 项自动测试通过**，覆盖独立查询、非法回复、未知计数、预览与设定值区分、自动刷新及失效处理、持久化边界。冻结自检新增 `siglent_scan_monitor`，验证实际预览按钮及模拟超时后的停止恢复；发行构建对目录包、单文件 EXE 和 ZIP 二次解压执行自检及 Windows 界面启动检查。

未连接真实 SSG3021X。手册列出独立查询，但其在用户固件、外部触发等待期间的响应仍需实机验证；自动测试不证明硬件不会丢触发。

完整解压新便携包，退出旧版后复制旧 `data/` 或导入配置，核对窗口标题 `v0.7.7`。连接 → 应用外部点触发配置 → 布防 → 点击“刷新当前值预览”；手动读取正常后按需开启自动刷新。若独立查询仍失败，保留 `data/diagnostics/siglent-*.json` 中的命令和原始错误，点击“停止扫描”确认 OFF。
