# Lab Control Center 0.7.8 发行说明

日期：2026-09-28；平台：Windows 10/11 x64。

## 修复当前值查询等待导致界面卡住

用户补充：旧版点击读取当前扫描值后，整个软件会卡住。代码与阻塞测试确认一条界面冻结路径：后台 SCPI 查询持有会话通信锁，首页定时刷新连接状态时，主线程的 `is_connected` 也等待同一把锁。即使查询在后台线程，主界面仍会随仪器无回复而停顿。0.7.7 更换查询命令未解决该锁等待问题。

0.7.8 将连接状态与身份的缓存读取移到独立的短锁，首页和设备窗口检查状态不等待 VISA I/O；实际读写仍使用原通信锁串行执行，避免并发命令错配。首次身份读取成功后才发布已连接，关闭前发布未连接；串行重连期间保留最近状态，重连失败后清除。连接标志是本地会话状态，不代表硬件持续可达或输出安全。

读取等待期间，界面和停止按钮可响应。“停止扫描”先排队，当前查询结束或超时后执行原有重连、身份校验、单次关断和 OFF 回读，不在查询未结束时并发发送停止。保留默认单次 VISA 超时 5000 ms；没有强制终止 VISA 原生调用。若厂商驱动不遵守超时或底层调用永久不返回，软件不能保证关断时限，需要在仪器面板停止。

保留 0.7.7 的独立频率/幅度预览、默认关闭的自动刷新和未知外部触发计数。查询异常关闭自动刷新并清空预览，不重新启用扫描或重放触发。

## 验证与升级

新增 3 项测试：阻塞查询期间连接状态读取、打开/关闭等待期间状态读取，以及真实首页状态刷新和停止按钮在慢查询期间的响应。修复前两项状态测试失败，修复后通过；全量 **262 项测试通过**。冻结自检新增 `siglent_slow_preview`，在持有通信锁的模拟慢查询期间验证首页刷新、Qt 定时器、排队停止和超时后恢复。

目录版、单文件 EXE 和 ZIP 二次解压均执行自检及 Windows 界面启动检查。未连接真实 SSG3021X；这修复了已复现的软件锁等待，不代表独立查询已经通过用户固件验证。

退出旧程序，将 v0.7.8 完整解压到新目录，复制旧 `data/` 或导入配置，核对窗口标题版本。先使用手动“刷新当前值预览”，确认正常后再按需勾选自动刷新。
