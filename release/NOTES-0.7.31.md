# 0.7.31：DG / Vaunix / SSG 跨设备同步与笛卡尔扫描

日期：2026-11-09。正式版本：[v0.7.31](https://github.com/Rechoncy/Rigol_Generator_GUI/releases/tag/v0.7.31)。正式附件与同组源码、说明、manifest 和 SHA-256 一起保存到 `dist/published/v0.7.31/`；旧版和用户数据保留。

## 行为变化

跨设备任务原来只列出 DG4000。现在可混合 DG、Vaunix LMS/BLX 和 SIGLENT SSG，选择同步联动或笛卡尔组合；每个轴绑定设备、通道、参数、单位，展开的联合点表可手工修改和保存。DG 保持五类双通道目标；Vaunix 和 SSG 支持单射频输出的频率及绝对功率 dBm，功率步长为 dB。DG 电压幅度与 RF 功率分开建模，旧任务和配置导入按明确类型校验，不重新解释旧 Vpp。

鼎阳支持两种参与方式，两者都使用完整展开表，支持同步与笛卡尔：

- **NI 软件逐点设置**：与 DG、Vaunix 一起按累计 NI 边沿驱动，首个边沿应用 P0，末点后循环。启动只读预检；SSG 检查原生扫描 OFF、闭环/IQ、有效频功与安全的设置顺序，每点 ESR 与参数回读校验，不自动重放未知接受结果。
- **原生列表 / 公共外部触发**：2–500 个联合点预装并完整回读，AUTO 扫描触发、EXT 点触发、正向连续运行。NI PFI 和 SSG EXT TRIG 分别接收同一外部信号；软件不逐点设置或发送 *TRG。原生驻留 0.01–100s；布防完成前暂停外部触发，启动期间观测到边沿会拒绝本次启动并收尾。

软件完成屏障、积压和点位仅针对软件步进组；原生 SSG 的实际接收数、内部积压和点位仍未知，不能用 NI 计数代替。只有原生参与的任务仅监视 NI，不制造软件完成数。手册 C01A 3.4.5.25–27 定义触发枚举及边沿，但未定义首沿消费和忙期队列；模拟器的首点行为不能替代实机确认。

## 失败与恢复

保留 DG/Vaunix 首触发 P0、CH2 隔离、有序累计计数、部分失败不回滚/不重放，以及 0.7.30 的 VISA 会话隔离。SSG 软件模式每点校验与回读会占用通信时间，吞吐量以实机观察为准；软件顺序屏障不保证电气同时生效。

原生参与者进入布防后，启动失败、取消、软件组失败和停止都要停止 SSG 并回读 OFF。任何 NI/原生清理失败保留控制器和租约，只有明确重试停止才能尝试恢复；显式重连后必须确认同一资源和完整身份，仅发送 OFF，不重传旧列表、重新布防或补发旧参数。停止扫描不自动关闭 RF。

列表准备期间的取消会在准备完成、发送扫描启用前再次检查，不因用户已请求停止而继续布防。旧单机扫描的默认调用行为保持。

完整回归另复现 Windows 升级辅助程序的状态文件共享冲突。状态 JSON 现在先写完整临时文件，再在同目录原子发布；只有共享冲突 32/33 限时重试，安装与应用启动仍各执行一次，其它 I/O 错误立即报告。该逻辑属于新版自带的升级辅助程序，不改写正在运行的旧版文件。

任务中增加 source_kinds、SSG 模式与驻留字段，旧任务仍兼容；设备类型变化或单位不适用会拒绝加载/启动，缺失设备不自动改绑。配置包导入导出保留同一语义。

## 验证与交付

本轮回归覆盖类型/单位和配置往返、三源同步与笛卡尔、首触发/累计顺序、部分失败、原生启动取消、OFF 失败保留及显式恢复。源码和冻结验收只使用内置模拟器与受控替身，不枚举或连接真实硬件。完整结果保存于 `dist/verification/0.7.31/` 和 `dist/verification/0.7.31-release/`，实际包内 Python、DLL、源码快照、冻结/隔离安装与校验值以同组 `release-manifest.json` 为准。

- 新增联动整组初次集成 **97 项 / 3.368 秒通过**，后补原生取消与 Windows 交接回归；UI 等待真实前端投递的相关 27 项连续 5 轮、共 **135 次通过**。
- 鼎阳适配器、原生生命周期及原 SSG/SSG3021X 兼容组合 **108 项 / 0.097 秒通过**；升级交接与更新相邻 **98 项 / 9.276 秒通过**。
- 最终本机完整回归 **929 项 / 127.547 秒，OK**；1 项因本机 Windows 符号链接权限跳过。初次 UI 等待错误、后续状态文件共享冲突的全量日志分别保留，修复后重新完成全量。
- 最终源码入口自检 `success=true`、`software_version=0.7.31`、`hardware_access=false`，新增 `multi_source_linkage` 十一项及全部既有检查通过。三类源的临时配置预览已核对单位、4 轴 / 4 参数列与 24 个联合点一致。

正式标签构建独立执行 Windows 全量、三格式冻结及隔离安装验收；以新提交的工作流和清单为准，不把本机源码结果当作已生成的正式产物。

未进行用户实机同步接线、首点、可接收触发速率或长时间运行验收；原生模式始终按未知接受状态呈现。详细接线、步骤和停止恢复见[使用说明第 11 节](../docs/USER_MANUAL_CN.md#11-跨设备联动任务中心)。
