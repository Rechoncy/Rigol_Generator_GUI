# Lab Control Center 0.7.20 发行说明

日期：2026-10-27；平台：Windows 10/11 x64。
正式发行：GitHub Release `v0.7.20`；未进行实体仪器验收。

本版完善 Newport SMC100CC / PR50CC 波片架的状态说明和手动恢复，保留 DG4000 快速重连后旧回读快照失效修复。便携 ZIP 和单文件 EXE 由标签对应提交构建，内置 Python、Qt、Python 仪器接口及 Vaunix Windows x64 SDK DLL，目标电脑无需安装 Python。

## 相对上一正式版 v0.7.18

- 带入 0.7.19 的 DG4000 缓存修复：共享连接快速断开和重连，即使中间断开状态未被界面观察到，也会清空原连接已经显示的频率、幅度、输出及回读时间；新连接上的有效请求不会被误清除。此检查不增加仪器查询或参数写入。
- 新增本版 Newport 中文状态与操作建议、显式恢复使能、归零状态拒绝后的正确回读，以及停止失败保留占用和显式清理。未开始的后台任务提交失败也能恢复完成标志，不再因空任务阻止关闭。
- 保留 v0.7.18 的 DG4000、SSG、Vaunix 参数回读、NI 记录及清理修复。原配置和任务格式、首触发点、有序积压、通道隔离及原生扫描恢复规则保持兼容。

## Newport 波片架状态与恢复

本版针对“点击归零后出现 NOT REFERENCED 提示、无法操作”的反馈，完善 SMC100CC / PR50CC 状态说明和手动恢复流程。现场没有保留状态码，不能据此确定实机当前故障；本轮修复由官方协议和纯虚拟最小复现确定的软件路径，不宣称实机已恢复。

- `NOT REFERENCED` 是尚未建立参考。`OR` 寻机械原点只适用于该状态且无硬件错误时；READY 时无需再次寻原点，想回到 0° 应使用绝对定位 0°。
- 状态显示中文及 `0xXX`，同时给出下一步操作。`0x10` 的 ESP 台型/配置错误、CONFIGURATION、运动中与未知状态分别说明，不统一提示归零。
- 增加显式“恢复使能（电机励磁）”入口：仅对适用的 DISABLE 状态发送本控制器地址的 `MM1`，检查命令错误并回读 READY。每次由用户点击，不自动广播、复位、寻原点或定位，也不自动重试未确认结果。
- MM1 按手册把设定点置于当前读到的位置，重新给电机励磁并恢复控制环；可能消除残余跟随误差，不能保证机械位置完全无微动。

## 已确认的软件缺陷与最小复现

1. READY 状态下点击寻原点，驱动在发送 `OR` 前拒绝；旧界面仍补发 `ST`，并把位置标成“读取失败”。本地状态拒绝现在保留原状态，通过后台只读查询确认位置，显示原拒绝原因，不补发停止。
2. 拒绝 `QThreadPool.start()`，使后台任务从未执行。旧路径虽然清除 busy，却遗留未完成标志，导致空任务持续阻止关闭；现在只对真正未开始的任务恢复完成标志，连接/断连同类路径一致。
3. 注入手动运动错误和停止失败。旧路径在停止未确认时仍释放租约并放开其他运动；现在保留原任务占用和清理待确认状态，用户显式重试停止，确认不再运动且状态可识别后才释放；未知状态不能当作停止成功。必要重连仅用于原任务停止，不重放 `PA` 或 `OR`。
4. 在未连接的设备窗口点击连接。旧路径先申请仅允许已连设备的租约，连接操作因而被拒绝；现在通过连接管理器执行独立连接流程，继续检查已有占用及连接过渡，连接与状态读取不自动运动。

普通 READY 寻原点拒绝在旧代码中也不必然导致永久锁定；真实不可操作原因可能还涉及实机状态、错误、通信或现有扫描清理。新界面提供状态与原始错误帮助定位，不能将一次软件回归替代现场机械验收。

## 使用

连接后点击“读取位置与状态”。已 READY 时直接绝对定位或微动；未建立参考且无硬件错误时点击“寻机械原点”；DISABLE 时显式点击“恢复使能（电机励磁）”，确认 READY 后再定位。需要返回 0° 时设置绝对目标为 0°。

出现停止清理待确认时，保留窗口与任务，先排除连接问题再点击停止入口重试；确认结束前不通过其他设备记录或窗口绕过占用。读取失败仍显示未知，最近错误记录在恢复成功后仍保留，TS 非零硬件错误继续报告；后续错误缓冲区被读取清空不能单独证明机械故障已排除。

停止按实际状态处理：手册不允许在未参考和 CONFIGURATION 状态发送 `ST`，明确回读到可寻原点的未参考状态或配置状态静止时，以状态确认结束清理，不反复发送会被拒绝的命令。未知状态或非零错误仍保留占用。连续点动应先按厂商流程退出，不能假定 `ST` 适用于所有点动状态；窗口占用 COM 时不并开厂商软件抢占串口。

## 边界与验证

未修改 DG/Vaunix 首触发 P0、有序累计计数、CH2 隔离、停止失败保留占用或未知接受结果不自动重放；SSG 使用仪器自身原生扫描及既有恢复规则。原配置和任务格式保持，本轮不自动操作任何实体设备。

完整源码回归 **529 项通过（本次日志耗时 1502.036 秒）**。新增状态驱动回归 18 项、Newport 窗口回归 26 项通过，窗口测试包含原有 12 项和新增 14 项，本版总共新增 32 项回归。源码虚拟自检通过；默认 1180×760 窗口的 READY、NOT REFERENCED 和 DISABLE 三种状态截图确认状态说明、按钮和提示可读。测试耗时仅为本次运行记录，不用于推断实机运动、查询或触发性能。

发布前完整 unittest、源码虚拟自检与针对性复现日志保存在 `dist/verification/0.7.20/`；对应 GitHub Windows CI 的 529 项回归亦已通过（该次 56.047 秒）。本地目录包、单文件 EXE 和 ZIP 解压后的冻结检查通过，作为开发阶段验收记录保留。各次耗时均不构成跨机器性能比较或实机结论。

正式标签流程会从对应提交重新构建目录包、单文件 EXE 和 ZIP，执行冻结自检与完整回归，全部成功后才发布附件；正式构建的实际结果、依赖和源提交须按同组 `release-manifest.json` 逐项核对，不以先前开发包的验收代替正式标签构建。
