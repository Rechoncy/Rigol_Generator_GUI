# Lab Control Center 0.7.1 发行说明

日期：2026-09-26

平台：Windows 10/11 x64

## 鼎阳 SSG3021X 修复

- AM 深度仍以百分比编辑和保存，下发时转换到手册规定的 0～1；30% 发送 `:AM:DEPTh 0.3`。
- 修复连接/状态查询失败也永久保留扫描占用的问题。未发现扫描运行、也未发送可能启动扫描的命令时，失败后可以关闭窗口、断开连接。
- 曾读到扫描启用或尝试启动扫描后失联时，仍要求停止并回读 OFF 后释放扫描占用；启动和触发不自动重放。
- 仪器明确拒绝命令或回读不一致时保留连接。真正通信失败才关闭会话，避免超时回复影响下次查询。
- 每条配置命令后读取 ESR；错误包含具体命令和类型，并停止继续下发。历史 ESR 错误明确标记“本批尚未发送”，读后清除事件值。
- 状态读取先核对扫描状态，未识别的枚举不再一律当作启用。脉冲端口输出状态移到显式详细查询，模式相关的周期/延时/触发沿/门控极性按实际模式读取。
- 从脉冲序列改为基础单脉冲时，先确认内部源及 SINGLE，再查询当前周期。
- 自动将错误诊断保存到 `data/diagnostics/siglent-*.json`，包含版本、型号、序列号、固件、资源地址、状态和最近错误；诊断页也可手动保存。
- SSG 占用提示改为“SSG 通信或原生扫描”，避免误称 NI 联动任务。

按 SSG3021X 普通型号的手册执行 `:FM:...`；用户提供的 Plus 手册使用 `:FM1:...`，不能替换到普通型号。Plus 型号仍只读。本次排查和未确认事项见 [专项核对报告](../docs/SIGLENT_SSG3021X_AUDIT_20260926_CN.md)。

## 便携文件与升级

- `Lab-Control-Center-0.7.1-windows-x64-portable.zip`：完整解压后运行目录内的 `Lab Control Center.exe`。
- `Lab-Control-Center-0.7.1-windows-x64.exe`：单文件版本。

两种格式均内置 Python/Qt/PyVISA 等 Python 依赖，实际 USB 连接仍使用已安装的 VISA 系统驱动。

关闭旧程序后，把旧便携目录的 `data/` 复制到新版 EXE 同级，或用 `--data-dir` 指向原数据目录。不要混用两版 `_internal/`。AM 的已存百分数无需转换；旧 v0.7.0 EXE 不会因源码修改自动获得修复。

## 验证边界

本版本进行源码自动回归和目录包、单文件、ZIP 二次解压运行检查；确切结果以随包 `release-manifest.json` 及开发日志为准。用户当前不在实机旁，未取得原始 USB 错误日志，未进行真实 SSG3021X 通信、固件或输出波形验收；不能据此断言首次连接失败的所有原因已经排除。
