# Lab Control Center 0.7.14 发行说明

日期：2026-10-23；平台：Windows 10/11 x64。  
本轮为本地构建，未上传 GitHub Release。

本版继续检查 DG4000/Vaunix NI 步进与跨设备联动，修复启动排队期间的停止交接、同资源别名绕过占用、Vaunix 触发重试及日志失败后执行状态丢失的问题。0.7.12 的触发优化/CH2 隔离和 0.7.13 的停止重试规则继续保留。

## 启动、停止与手动操作

- DG/Vaunix 启动任务仍排队、执行或等待完成回调时，停止先登记取消；等该启动 CallTask 结束后再派发停止清理。
- 启动、停止和错误回调绑定各自的 controller/task 身份，迟到的旧回调不能清除新任务控制器或释放新租约。
- Vaunix 手动操作在提交和后台实际执行时都检查占用，并以设备事务锁执行，防止手动命令插入正在进行的任务。
- Vaunix 连接状态缓存使用短锁，首页查询缓存无需等待长时间 SDK 调用；缓存状态不代替实际 USB 回读。

停止超时或 NI 清理失败仍保留控制器及设备占用，可在条件恢复后点击“重试停止”。已经提交的 VISA/SDK 操作无法强制撤回；停止任务不会自动关闭仪器输出或回滚已接受的参数。

## 同资源连接与首页编辑

DG4000、SSG 和通用 SCPI 的相同规范化 VISA 地址共用资源占用身份。新保存拒绝跨类型重复地址；旧配置仍可读取，但同地址记录不能同时连接，也不能通过另一记录插入手动命令或启动任务。

连接/断开期间会保留该资源，阻止并发别名连接、任务获取及全局关闭绕过检查。相同地址的大小写、首尾空白会归一化；不同 USB/LAN 地址不会自动合并为同一实体仪器，应保持一致的实验连接入口。

后台探测也遵守资源占用。探测尚未结束时点击连接会合并为一个待连接请求，完成探测后再连接；创建虚拟实验室直接连接，避免重复探测与连接竞争。

首页编辑/删除尊重设置窗口拒绝关闭的结果。任务或后台操作未结束时，保留设备记录和原窗口，完成停止后再操作；通用 SCPI 原始查询/写入尚未返回时也保留任务并拒绝关闭。

SSG 窗口仍能完成自身首次连接和必要的停止恢复；授权只限当前设备记录，首页或同地址别名不能借此重连正在运行的扫描。恢复后先确认仪器实际状态，继续实验须按要求重新布防。

## Vaunix 触发与重试边界

- 真实与虚拟设备的任务写入器均绑定连接代次。断开或重连后旧写入器在设置前拒绝执行，需停止并重新布防，不恢复旧积压。
- 每点所有参数先校验后下发，拒绝空点、CH2、不支持的参数与越界数值。
- NI 触发点 setter 失败不重发；开始扫频、非 STOP 的序列控制和保存设备设置也只调用一次。
- 普通幂等设置/读取及 STOP 保留原有短暂 USB 错误重试。失败可能发生在设备接受操作之后，不能把报错理解为设备完全没有动作。

## 日志失败后的真实执行状态

跨设备控制器先保留本点实际设备结果；全部成功才更新完成计数，然后写 CSV。日志写入失败时停止后续点，同时保留本点全部或部分执行情况及原始设备错误，避免把磁盘失败误当成尚未下发。

CSV 可能缺失最后一条记录，不能仅凭缺行自动重放。本点已经接受的设置不会回滚；应记录界面错误、核对仪器状态，修复保存路径后再准备实验。已有空 CSV 首次写入会补齐表头。

## 验证范围和使用边界

本版回归重点包含排队启动立即取消、旧回调身份隔离、同资源别名与连接过渡、窗口拒绝关闭后的记录保留、Vaunix 单次 SDK 调用与重连失效，以及 CSV 失败时的完成/部分结果保存。源码回归与冻结产物运行分开记录，发行产物的运行证据由 `release-manifest.json` 保存。

完整自动回归 382 项全部通过，耗时 52.372 秒。

源码自检已通过，包含 DG 的 CH2 通道隔离、Vaunix 25 个累计边沿的频率/功率顺序与重连失效检查，以及 SSG 断线后的停止恢复；RF 保持 OFF。编译产物的目录包、单文件 EXE 和 ZIP 解压后自检结果分别保存于发行清单，不等同于实体仪器验收。

本版未进行实体仪器操作，也未测量实机触发延迟或输出稳定时间；0.7.12 的本机模拟基准保留为历史资料。
