# Lab Control Center 0.7.9 发行说明

日期：2026-09-28；平台：Windows 10/11 x64。

## 独立扫描页面与底部状态卡片

本次直接修改项目 Python 源码，再由同一份源码构建便携 ZIP、单文件 EXE 和源码 ZIP。并非只修改编译包；`src/rigol_control/ui/siglent_window.py` 是本次界面修改的主要文件，先前通信锁修复保留在 `src/rigol_control/drivers/scpi.py`。

- 侧栏拆分为“触发步进扫描”和“列表扫描”。STEP 页显示起止频率、幅度、点数、统一驻留与形状；LIST 页显示逐行频率、幅度、驻留和列表管理，不再混放两种输入。
- 两页分别保存扫描量、方向、模式、扫描触发、点触发与触发沿，各自有应用、布防、执行单次按钮。切换页面只切换编辑器，不执行 SCPI。
- 布防和单次执行必须与当前页已应用的配置一致，避免在 STEP 页启动先前的 LIST 配置或反之。两页控制同一台仪器，同一时刻只能运行一个原生扫描。
- 参照 RIGOL/NI 联动页复用 `metric_card`，将已收到触发、待处理积压、当前扫描频率、当前扫描幅度放在页面底部。参数区可滚动，操作按钮和底部预览保持可见。
- 频率按 GHz/MHz/kHz 显示，悬停可看 Hz；幅度以 dBm 为主，下方显示 50 Ω 正弦载波的 mV/mVpp。接收和积压仍为未知，不估算次数。
- 两页共用一个仪器预览和刷新计时器，切页不会清零或伪造回读。自动刷新默认关闭且不持久化。保留 v0.7.8 查询等待期间的界面响应修复和断线停止恢复。
- 旧版共用扫描参数迁移到两页；旧 STEP 参数、LIST 表格和电压单位保留。迁移后的两页参数独立保存，恢复配置不自动应用或启动仪器。

## 验证

新增 4 项回归，覆盖页面切换无命令、底部共享预览、跨页配置启动保护、旧参数迁移及独立保存、无效 LIST 草稿不影响 STEP。全量 **266 项测试通过**。冻结自检增加 `siglent_scan_pages`，覆盖两页、底部面板、LIST 应用/布防/停止和跨页保护。目录版、单文件及 ZIP 二次解压运行检查通过；未连接真实 SSG3021X。

解压 v0.7.9 到新目录，退出旧版后复制 `data/` 或导入配置。日常操作选择对应扫描页，应用配置后布防；底部“刷新当前值预览”按需读取，确认实机正常后才启用自动刷新。
