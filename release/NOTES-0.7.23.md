# Lab Control Center 0.7.23

日期：2026-10-28；平台：Windows 10/11 x64。
状态：本次按用户授权以 [v0.7.23 GitHub Release](https://github.com/Rechoncy/Rigol_Generator_GUI/releases/tag/v0.7.23) 正式发行，由标签提交通过 GitHub 发布工作流构建、验证并发布。正式附件本地副本使用 `dist/published/v0.7.23/`；已验收的 `dist/local/v0.7.23/` 开发包、原便携包、独立 EXE、历史构建和旧正式附件分别保留，不覆盖。

## 可安装 EXE

新增 `Lab-Control-Center-0.7.23-windows-x64-setup.exe`，按当前 Windows 用户安装，提供开始菜单入口与卸载项。安装程序内含应用的 Python/Qt 和 Python 仪器接口，目标电脑无需外部 Python；真实仪器的 VISA、NI-DAQmx、串口或 USB 系统驱动仍需准备。

默认程序目录为 `%LOCALAPPDATA%\Programs\LabControlCenter`，默认用户数据目录为 `%LOCALAPPDATA%\RigolGeneratorControl\data`，安装向导可选择已有独立数据目录。程序文件与用户数据分离，`--data-dir`、`RIGOL_GUI_DATA_DIR` 仍可覆盖，后续自动升级沿用当前实际目录。正常卸载保留独立用户数据及安装备份。

## 下载后自动安装并保留数据

安装版检查 GitHub 更高的正式 Release，优先下载适用的 `-setup.exe`。下载后核对字节数、SHA-256 和完成路径，再交接安装；草稿、预发布、main 提交和裸标签不作为正式更新，旧正式版不会导致本地降级。

“下载后自动安装（空闲时）”默认开启，也可关闭后点击“安装更新”。存在扫描、触发、模拟采集、后台通信、配置导入或未确认清理时，保留当前任务与程序，自动请求等待空闲；用户可关闭自动安装取消等待。正常关闭被接受后，Windows 自带 PowerShell 交接程序等待旧进程退出，再启动安装程序；不会强制结束实验或通过更新重放仪器操作。

安装程序先完整备份所选用户数据，再卸载登记的旧安装版、安装新版，最后核对已有文件并恢复缺失文件。备份包括数据目录内的配置、参数、任务、更新偏好、日志、测量文件和空目录，排除 `updates` 下载缓存；默认备份位于 `%LOCALAPPDATA%\RigolGeneratorControl\installer-backups`。数据目录外的采集文件不移动或删除，需要单独备份。

备份失败会阻止卸载。已存在且内容一致的数据继续使用；同名内容不同、备份损坏或恢复失败时，保留原数据与备份并报告，不静默覆盖。安装中断后数据仍保留，但不承诺旧程序自动回滚；保留日志，排除环境问题后可重新运行安装程序。安装后重新打开软件读取原配置，不自动开启 RF、扫描或机械运动。

便携 ZIP 和直接运行的独立 EXE 继续采用原有下载后手动迁移流程，不直接执行下载的独立程序进行安装。旧便携版首次迁移时先停止并退出旧版，再运行 Setup，选择原 `data/` 或导入配置；配置包不包含采集文件。详见[安装版操作与升级](../docs/USER_MANUAL_CN.md#45-安装版-exe-与保留数据升级)。

## 实现与验证范围

安装包采用 Inno Setup 和同一已验证的目录应用载荷。安装标记、运行/安装互斥、数据快照、退出交接和安装后的恢复各自保留错误信息。安装数据检查不初始化 Qt、VISA、NI、串口或 Vaunix，也不启动真实设备；自动交接脚本保存在程序目录外，防止卸载旧程序时删除交接文件。

交接前先提交正在编辑的数值并保存设备参数；保存失败时取消交接、保留程序，不用旧保存值继续退出。真实 Windows PowerShell 验证发现无 BOM 的 UTF-8 中文脚本会在系统 PowerShell 中解析失败，现生成带 UTF-8 BOM 的交接文件，并由原生 PowerShell 验证父进程退出等待及未提交票据不能安装，未执行安装程序或访问硬件。

实际安装测试另修正了带引号的中文旧版卸载路径解析、Inno 标准卸载键重建后数据目录元数据的保存、旧卸载临时工作进程退出等待，以及数据路径内花括号的字面值保持。交接已提交而撤回写盘失败时，保留原进程，不能在取消状态未确认时退出。冻结自检分别检查安装版外部数据与便携版 EXE 旁 `data/`；Windows CI 的 8.3 临时路径先规范化后比较。隔离验收安装使用独立实例后缀及互斥锁，并拒绝自动安装生产 Setup，生产安装的空后缀行为保持不变。

真实交接还复现了 Windows PowerShell 5 在当前继承环境中无法加载 `Get-FileHash` 的问题；安装前的 SHA-256 改由 .NET 流式计算，不依赖该命令。原生交接已验证：有提交但父进程仍在运行时不执行、父进程正常退出后执行校验与安装请求、完整传递中文及特殊字符路径，再以同一数据目录重启应用。交接验收使用两个仅记录参数的本地测试 EXE，不执行真实安装或访问硬件。

隔离安装实测已完成首次安装、运行中阻止替换、备份失败阻止卸载、卸载旧程序再安装、数据字节与空目录保留、缺失文件恢复、安装版正常启动与冻结自检、普通卸载后找回自定义数据目录并重装。最终交付的每项结果仍以本组构建清单为准。

最新完整源码 unittest 执行 **666 项，结果 OK（79.822 秒）**，其中 1 项符号链接测试因 Windows 链接权限跳过；安装标识、控制器、默认目录和构建等 **39 项针对性检查全部通过**，原有联网更新 **71 项全部通过（0.562 秒）**。最新源码虚拟自检通过，安装生命周期七项与原有检查继续保留。原生 PowerShell 交接验证记录为 `handoff-acceptance.json`，`parent_exit_waited=true`、`no_commit_prevents_install=true`；源码/交接验收不等同于重编译后的实际安装及冻结产物验收。

本版针对性测试、完整 unittest、源码虚拟自检、冻结产物和隔离安装/升级/卸载的实际记录保存在 `dist/verification/0.7.23/`，不沿用上一版结果作通过声明。正式发行包含 Setup EXE、便携 ZIP、独立 EXE、源码快照、发行说明、SHA-256 与构建清单共七个附件；具体字节、源码提交、内置运行时和安装验收以正式发布的本组 `release-manifest.json` 为准。安装测试使用独立产品标识与临时路径，不覆盖用户已有安装或数据。

本轮不修改仪器协议，不自动操作实体仪器；保留 DG/Vaunix 首触发 P0、有序累计计数、CH2 隔离、停止失败保留占用、未知接受结果不自动重放，以及 SSG 自身原生扫描和恢复规则。
