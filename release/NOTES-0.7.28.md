## 使用

DG4000、Vaunix 和鼎阳 SSG 的回读区新增“自动回读（下发后 / 触发空隙）”，默认勾选，可取消。成功下发参数或触发步进的已应用点发生变化后，软件在可用空隙更新频率、幅度/功率与输出状态；仍保留手动回读按钮。只编辑参数、连接设备或恢复本地窗口参数，不会因此发起本功能的自动查询。

自动结果仍与待应用编辑框分开，不把仪器回读写进编辑参数。DG 的 Vpp/mVpp 本地显示、原生负 dBm/Vrms 和空单位高低电平差来源提示均保留，不猜测负载、波形或跨单位换算。新自动控件跳过持久化，不改用户 DATA 或配置包。

自动失败以回读区状态说明，整组显示未知；不弹出连续模态错误，不在后续触发到来时循环重试。手动回读成功，或取消勾选后重新勾选，可恢复自动调度。断连、连接代次更换、后续写入或过期票据使旧结果失效，不把迟到快照当作当前值。

关闭窗口会先取消自动回读并停止调度定时器；若窗口因任务/清理占用拒绝关闭，自动选项已取消，仍需保留原任务及占用，手动回读仍可用，重新勾选可恢复自动。单独取消自动不会清掉无新写入的有效缓存，仍可在本地切换 Vpp/mVpp；旧的在途自动票据仍会失效，后续真实输出变化也仍使旧值未知。关闭不强退通信或重放操作。

## 调度与时序边界

- 成功写入或已应用触发点变化只标记待刷新；调度定时器每 100ms 检查一次条件，等待约 150ms 的安静窗口，并让本调度器新增的读取请求至少间隔 500ms。多个变化合并为一次快照，不对每个触发边沿查询；没有新事件时不持续回读。定时器检查条件不等于每 100ms 访问仪器；SSG 复用已有快照不追加查询，不属于这里的新增请求。
- 有积压、任务启动/停止中、后台操作或未能确认的占用时先让写入和清理完成；停止确认后，最后一次未读变化可补读。高速触发没有空隙时，自动显示可能延后或保持未知，不能用回读次数代替已完成触发数。
- DG 和 Vaunix 在每条查询/Getter 前后检查真实控制器、接收/应用计数、连接代次、写修订及请求票据；新的触发/写入使旧读取让位或失效。活动跟踪按规范资源地址关联主窗跨设备联动和单机任务，也考虑 Vaunix 共享 SDK DLL 的活动，不仅依赖当前窗口按钮。
- 单条已经开始的 USB 查询或 SDK Getter 无法强行撤回，仍可能占用通信时段并延迟随后到来的触发。合并与让位减少争用，不承诺零延迟、每边沿回读或输出已物理稳定；有严格时序要求时可关闭自动回读并按需手动读取。
- SSG 正常自动回读复用已有合法的频率、功率和 RF 三字段快照，原生扫描沿用约 1500ms 的既有监测。自动已暂停或取消、且没有独立当前点预览时，只保留 `SWEep:STATe?` 安全状态检查，不反复查询已失败的基本频率/功率；独立预览仍遵循自己的选项。自动选项不停止仪器原生扫描，不加入 NI 逐点控制，也不按软件快照推断真实外部触发接收数或积压。
- 失败不自动重连、清缓冲、重放写入或释放未确认的设备占用。DG/Vaunix 首触发 P0、有序累计计数、CH2 隔离、停止失败保留占用，以及 SSG 自身原生扫描和恢复规则保持。
