## 单位依据与实施方案

用户希望 DG 回读兼容 mVpp 和 dBm。DG4000 原厂手册的 `VOLTage:UNIT?` 返回单位为 VPP、VRMS 或 DBM；mVpp 是带毫前缀的电压数值表达，不把 `MVPP` 当作该查询返回的另一种仪器单位。本版保留驱动对真实单位的解析，在界面本地处理 Vpp/mVpp 显示选择。

- 回读区 CH1、CH2 分别提供 Vpp/mVpp 显示选择。仅当快照 `amplitude_unit=VPP` 时应用，Vpp 转 mVpp 乘以 1000，例如 `0.002 Vpp` 显示为 `2 mVpp`；切回 Vpp 使用同一缓存原值，不累积换算误差。
- `DBM` 是仪器原生单位，负数有效，例如 `-20 dBm` 保留为 `-20 dBm`；不因为选了 mVpp 就将功率换算为电压。`VRMS` 同样保留仪器原数值并显示 Vrms。
- 不按假定的 50 Ω、正弦或 RMS 关系在 Vpp、Vrms 和 dBm 之间猜算；回读结果仍是配置参数快照，不是端口瞬时电气测量。
- 切换显示只重绘最近一次有效快照，不访问仪器，不修改频率/幅度编辑框、面板单位、输出或负载，不启动回读或任务。
- 新显示控件不进入持久化：整个回读区继续跳过设备参数保存，选择不写 `device_parameters.json`、用户数据或配置包。失效/断连/连接代次变化后仍显示未知，切换不能恢复旧快照。
- 0.7.26 的空单位兼容路径保留。高低电平差得到的 Vpp 也可显示为 mVpp，但仍明确标注“高低电平差；仪器当前幅度单位未知”；它不提供猜测 dBm 的依据。

## 使用

在“通道与波形”底部点击“回读频率 / 幅度”。回读显示 Vpp 时，可在对应通道切换 mVpp；两个通道互不影响。仪器返回 dBm 或 Vrms 时，仍按该原生单位显示，不执行电压前缀转换。来源说明可区分仪器原单位幅度与高低电平差兼容值。

此改动只涉及回读显示，不增加 SCPI 查询，也不修改原来的幅度设置输入。回读失败后继续显示未知；输出关闭时，保留的参数不代表端口正在输出。DG4162 USB 的空单位回复根因和此前兼容的实机效果仍未确认，不因新增显示单位就宣称硬件问题已解决。
