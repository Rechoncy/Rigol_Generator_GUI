# Lab Control Center 0.7.2 发行说明

日期：2026-09-26；平台：Windows 10/11 x64。

## SSG3021X 手册复核与幅度单位

按用户提供的普通型号 `SSG3000X_ProgrammingGuide_C01A.pdf` 复核当前驱动的 57 项命令头，全部能在手册中找到。测试后端增加独立的命令头白名单，防止虚拟后端过于宽松而接受不属于普通型号的命令。维持 v0.7.1 的 AM 比例、状态读取和窗口占用修复；不将 Plus 的 FM1 命令套到普通型号。

- 固定 RF 幅度、STEP 起止幅度和 LIST 幅度列增加 **dBm / mV / mVpp**。
- 电压按 **50 Ω 匹配负载上的正弦载波**换算：mV 为有效值，mVpp 为峰峰值。调制后波形的整段有效值不等于载波设定值。
- C01A 支持 mV、幅度查询返回 dBm，没有列出 mVpp 命令单位。软件将输入统一换算为 dBm 后校验并发送，不发送未规定的 `mVpp` 后缀。
- 幅度回读按 0.01 dB 设置分辨率校验，固定输出、STEP 端点和 LIST 均接受一个分辨率步长内的舍入/截断差异，避免电压换算值误报；更大偏差仍报错，频率和驻留校验不变。
- 切换单位自动换算、保留相同幅度，不发送仪器命令，也不会因显示舍入使已准备扫描变成“已有编辑”。
- LIST 使用一个独立单位选择器，读取仪器列表后按当前单位显示；非法幅度单元格阻止单位切换，避免部分行已换算而其他行未换算。
- STEP 幅度扫描仍按仪器的 **dBm 线性步进**；电压端点编辑不会变成电压线性扫描。需要电压等步长时使用 LIST 手工填写。
- 单位和编辑值自动保存；0.7.0/0.7.1 保存的 dBm 参数和列表按原含义恢复，无需手动转换。
- Python API 支持 `driver.set_power(100, "mV")` 或 `driver.set_power(200, "mVpp")`；原来的 `driver.set_power(-20)` 保持 dBm 含义。

详细依据、示例和验证边界见 [核对报告](../docs/SIGLENT_SSG3021X_AUDIT_20260926_CN.md)及[使用说明](../docs/SIGLENT_SSG_CN.md)。

## 本地文件与升级

- `Lab-Control-Center-0.7.2-windows-x64-portable.zip`：完整解压后启动 `Lab Control Center.exe`。
- `Lab-Control-Center-0.7.2-windows-x64.exe`：单文件版本。
- 两种格式均包含独立 Python/Qt 和 Python 接口依赖；真实 USB 仪器仍使用系统 VISA 驱动。

关闭旧版后，把原 `data/` 复制到新版 EXE 同级，或通过 `--data-dir` 使用原数据目录。保留两版目录，避免混用 `_internal/`。

## 验证边界

全量源码回归 **239 项通过**，含新增电压参考值/边界/非法值、单位 API、STEP/LIST 换算、显示切换、参数恢复与旧 dBm 配置兼容测试。便携包执行目录、单文件、ZIP 二次解压自检和普通 Windows Qt 启动检查，记录见构建清单 `release-manifest.json`。没有连接用户的真实 SSG3021X，原 USB 故障是否另有固件/通信原因仍需实机诊断报告确认。
