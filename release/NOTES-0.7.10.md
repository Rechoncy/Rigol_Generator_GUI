# Lab Control Center 0.7.10 发行说明

日期：2026-10-10；平台：Windows 10/11 x64。

## 取消输入框滚轮改值

鼠标悬停在数值框上滚动页面时，原有 Qt 数值框会增加或减小数值；频率、幅度、扫描点数和采集参数可能因此被无意修改。本版从源码统一禁用此交互，再用相同源码构建便携包、单文件 EXE 和源码包。

- 全部设备页、联动页及动态新增的数值输入框均不再通过滚轮改值，已有输入焦点时也不改值。
- 单位和参数下拉框在收起状态下不再通过滚轮切换，避免参数或单位被误改。展开列表后仍可用滚轮浏览选项。
- 鼠标位于输入框及其内部文本区域时，滚轮转交最近的页面或表格滚动区域；页面仍正常滚动。
- 手工输入、键盘方向键、数值框增减按钮和点击选择下拉选项保持可用。
- 不改变保存的参数、SCPI 命令或仪器扫描行为；保留 0.7.9 的独立 STEP/LIST 页和之前的通信修复。

## 验证

新增 3 项输入交互回归，验证整数/小数/带单位输入在有无焦点时均不改值、不发数值变更信号，输入框上的滚轮仍滚动页面，展开的下拉列表仍可滚动，以及键盘输入仍可用。全量 **269 项测试通过**。

冻结自检增加 `input_wheel_policy`，对六台虚拟设备窗口中的实际数值框与下拉框逐一发送上下滚轮事件，验证各参数保持原值。目录包、单文件 EXE 和 ZIP 二次解压自检及 Windows 界面启动检查通过。未操作实体硬件。

退出旧版后将新 ZIP 完整解压，复制原 `data/` 或导入配置，核对窗口标题为 v0.7.10。
